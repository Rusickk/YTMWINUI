## О приложении

> YouTubeMusic-WINUI объединяет веб-интерфейс YouTube Music с нативной средой Windows, дополняя его материалами Fluent Design из Windows 11, синхронизированными текстами песен, улучшением звука и блокировкой рекламы.

---

## Возможности

| Категория | Возможность | Описание |
| :--- | :--- | :--- |
| **Интерфейс и дизайн** | Материалы Windows 11 | Поддержка фонов `Mica`, `Mica Alt` и `Desktop Acrylic` |
| | Темы оформления | Системная, тёмная и светлая темы |
| | Гибкая навигация | Переключение между боковой панелью слева и верхним меню |
| | Встроенный мини-плеер | Управление воспроизведением прямо в панели навигации |
| | Поиск и история | Поисковые подсказки и локальная история запросов |
| **Тексты и полноэкранный режим** | Синхронизированные тексты | Построчные таймированные и обычные тексты песен из базы LRCLIB |
| | Автопрокрутка и переход | Следование за играющей строкой и перемотка трека по клику на текст |
| | Перевод текстов | Перевод строк в реальном времени с фильтром исключения языков |
| | Полноэкранный плеер | Экран плеера с анимированным размытым фоном обложки трека |
| **Воспроизведение и звук** | AdBlock | Блокировка видеорекламы и баннеров в плеере |
| | SponsorBlock | Автоматический пропуск спонсорских вставок, интро и завершений |
| | Кроссфейд (Crossfade) | Плавные переходы громкости между треками |
| | Качество воспроизведения | Принудительный выбор максимального битрейта аудио и выбор качества видео |
| **Сеть и доступность** | Обход ограничений | Встроенный локальный Sing-box SOCKS5 прокси для доступа к YouTube Music |
| | Быстрое переключение | Включение и отключение прокси в настройках приложения в один клик |

## Системные требования

| Компонент | Требование |
| :--- | :--- |
| **Операционная система** | Windows 10 (версия 1809 / сборка 17763 или новее) или Windows 11 |
| **Фреймворк** | Windows App SDK / WinUI 3 |
| **Среда выполнения** | Microsoft Edge WebView2 Evergreen Runtime |
| **Архитектура** | x64 |
