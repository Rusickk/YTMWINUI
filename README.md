## About

> YouTubeMusic-WINUI integrates the YouTube Music web interface into a native Windows desktop shell, combining Windows 11 Fluent Design materials, synchronized lyrics, audio enhancements, and ad blocking.

---

## Features

| Category | Feature | Description |
| :--- | :--- | :--- |
| **Interface & Design** | Windows 11 Materials | Support for `Mica`, `Mica Alt`, and `Desktop Acrylic` backdrops |
| | Custom Themes | Full support for Dark, Light, and System color schemes |
| | Flexible Navigation | Toggle between a left sidebar and a compact horizontal top menu |
| | Mini-Player | Integrated playback controls directly inside the navigation bar |
| | Search & History | Search suggestions with local query history |
| **Lyrics & Visuals** | Synchronized Lyrics | Time-synced and plain lyrics from the LRCLIB database |
| | Auto-Scroll & Seek | Real-time lyrics following with click-to-seek playback |
| | Live Translation | In-app real-time translation with language exclusion filters |
| | Fullscreen Mode | Immersive player with animated blurred album artwork background |
| **Playback & Sound** | AdBlock | Suppresses video advertisements and promotional banners |
| | SponsorBlock | Automatically skips sponsored segments, intros, and outros |
| | Audio Crossfade | Smooth volume transitions between tracks |
| | Quality Control | Forced maximum audio bitrate and configurable video resolution |
| **Network & Privacy** | Bypass Restrictions | Local Sing-box SOCKS5 proxy to access YouTube Music in restricted regions |
| | Single-Click Toggle | Enable or disable the proxy directly in settings without affecting system VPN |

| Component | Requirement |
